NightCompare

Alkollü Mekan Fiyat Karşılaştırma Uygulaması — Proje Dokümantasyonu

Sürüm 0.1.0 (Flutter)

1. Proje Genel Bakışı

NightCompare, kullanıcıların alkollü mekanlardaki güncel içki fiyatlarını karşılaştırmasına, gece rotaları oluşturmasına ve bütçe planlaması yapmasına olanak tanıyan Flutter tabanlı bir mobil uygulamadır. Koyu tema, mor/elektrik mavisi renk paleti ve cam efekti (glassmorphism) ile modernize edilmiş görsel bir tasarıma sahiptir.

2. Proje Dosya ve Klasör Yapısı

lib/
├── main.dart                       # Uygulama giriş noktası
├── theme/
│   ├── app_colors.dart             # Renk paleti (mor, elektrik mavisi, dark bg)
│   ├── app_typography.dart         # Tipografi + 8pt spacing sistemi
│   └── app_theme.dart              # ThemeData (Material 3, dark)
├── widgets/
│   ├── glass_container.dart        # Cam efekti (blur+saydamlık) temel bileşeni
│   └── venue_card.dart             # Mekan kartı + fiyat karşılaştırma satırı
├── models/
│   └── venue.dart                  # Venue, DrinkPrice, PriceLevel modelleri
├── data/
│   └── mock_venues.dart            # Test verisi (Efes örneği dokümandan)
└── screens/
    ├── root_shell.dart             # Bottom nav + FAB (5 sekme)
    ├── home_screen.dart            # Keşfet (Ana Sayfa)
    ├── venue_detail_screen.dart    # Mekan Detay (Fiyatlar/Yorumlar/Hakkında)
    ├── compare_screen.dart         # Karşılaştır (arama+kategori+sıralama, Akış 1)
    ├── contribute_screen.dart      # Katkı formu: Mekan→İçki→Fiyat (Akış 4)
    ├── favorites_screen.dart       # Favoriler (Mekan/İçki/Şehir sekmeleri)
    ├── profile_screen.dart         # Profil, istatistikler, rozetler
    ├── budget_planner_screen.dart  # Bütçe Planlayıcı (Akış 2)
    └── night_route_screen.dart     # Gece Rotası + canlı rota görünümü (Akış 3)

3. Bağımlılıklar (pubspec.yaml)

Kategori Paket Sürüm Açıklama
State Management flutter_riverpod ^2.5.1 Uygulama durum yönetimi
Backend supabase_flutter ^2.5.6 Veritabanı ve kimlik doğrulama
Harita & Konum google_maps_flutter, geolocator ^2.6.1 / ^12.0.0 Mekan konumları ve cihaz konumu
UI & Tasarım google_fonts, glassmorphism, fl_chart, shimmer, flutter_animate Çeşitli Tipografi, grafikler, yükleme efektleri ve cam tasarımı
Yardımcılar go_router, intl ^14.2.0 / ^0.19.0 Sayfa yönlendirmeleri ve tarih/para formatlama

4. Kurulum ve Çalıştırma

Projeyi kendi yerel geliştirme ortamınızda çalıştırmak için aşağıdaki komutları kullanabilirsiniz:

# Bağımlılıkları indirin
flutter pub get

# Uygulamayı başlatın
flutter run
