Event System

Event Architecture

Event'ler 3 kategoriye ayrılır: Scheduled (takvim bazlı), Triggered (oyuncu/AI eylemlerinden), Random (procedural). Her event bir EventScript objesi olarak tanımlanır:

EventScript {
  id: "economic_crisis_2008",
  triggers: [{type: "probability", value: 0.001, per: "day"}],
  preconditions: [{type: "market_volatility", operator: ">", value: 0.3}],
  effects: [
    {type: "modify_global", target: "stock_index", operation: "multiply", value: 0.7},
    {type: "modify_global", target: "unemployment", operation: "add", value: 0.05},
    {type: "spawn_news", template: "crisis_headline"}
  ],
  duration: {min: 180, max: 365, unit: "days"},
  cooldown: 730
}

Event Chains

Event'ler birbirini tetikleyebilir. Örnek zincir: Tech Startup Boom → Speculative Bubble → Market Correction → Regulatory Crackdown.

Deployment Pipeline

  1. Build: Docker image oluşturma, asset bundle
  2. Test: Otomatik test suite, security scan
  3. Stage: Staging environment deploy, QA onayı
  4. Canary: %5 trafik ile production testi
  5. Full Rollout: Tüm sunuculara dağıtım
  6. Rollback: Anlık geri alma (blue-green deployment)
